Repo stats
----------

Repository and citation statistics for [bilby](https://github.com/bilby-dev/bilby).

Generates git statistics (e.g. commits, issues, pull requests) of a repository
using GitHub's GraphQL API, and citation statistics using the NASA ADS
publication database's API.

Produces text files of processed data, a summary dashboard image and plots,
styled to match the [bilby website](https://bilby-dev.github.io). The images
are designed to be used in a README, documentation or web page.

Adapted from [astropy/repo_stats](https://github.com/astropy/repo_stats), and
readily generalizable by updating the input file `repo_stats/parameters.json`
(see `parameter_descriptions.json`). Essential parameters to update:
`repo_owner`, `repo_name`, `labels`, `bibs`, `bib_names`. Run with

```
python -m repo_stats.runner -a "<ADS_TOKEN>" -g "<GITHUB_TOKEN>"
```

where the tokens are for access to the [NASA ADS API](https://ui.adsabs.harvard.edu/help/api/)
and the [GitHub GraphQL API](https://docs.github.com/en/graphql/guides/forming-calls-with-graphql).

## Outputs

Written to `cache/` (or the directory passed with `-c`), where `<repo>` is
`repo_name`:

| File | Contents |
| --- | --- |
| `<repo>_user_stats_{light,dark,transparent}.png` | Summary dashboard |
| `<repo>_citations.{png,svg}` | Refereed citations per year |
| `<repo>_activity.{png,svg}` | PRs and issues opened/closed, and commit authors, per month |
| `<repo>_open_items.{png,svg}` | Currently open issues and PRs per label |

Each plot also has a `_dark` variant (e.g. `<repo>_citations_dark.png`) for
dark backgrounds; in HTML use a `<picture>` element with
`media="(prefers-color-scheme: dark)"` to switch between them.

For current output files, see the `cache` branch.

## Theme

Colors and fonts follow the bilby website: the bilby logo
(`dashboard_template/bilby_logo.jpg`) and
[Source Sans 3](https://github.com/adobe-fonts/source-sans) (SIL Open Font
License, see `dashboard_template/SourceSans3-OFL.txt`). The dashboard template
images are generated by

```
python repo_stats/user_stats.py
```


Stats website
-------------

`site/build.py` turns the cache directory into a small static website (plots,
headline numbers from `<repo_name>_summary.json`, light/dark aware) styled to
match [bilby-dev.github.io](https://bilby-dev.github.io). Build and view it
locally with

```
python site/build.py --cache cache --out _site
python -m http.server --directory _site
```

The `update_stats.yml` workflow regenerates the stats daily (or on demand via
*Run workflow*), pushes them to the `cache` branch and deploys the site to
GitHub Pages. To enable it:

1. In the repository's *Settings → Pages*, set *Source* to **GitHub Actions**.
2. In *Settings → Secrets and variables → Actions*, add an `ADS_TOKEN`
   repository secret holding a [NASA ADS API token](https://ui.adsabs.harvard.edu/help/api/).
   (`GITHUB_TOKEN` is provided automatically.)

Pull requests to `main` run the same build with live data but don't deploy it;
the built site is attached to the workflow run as the `stats-site-preview`
artifact (download it and open `index.html`).
